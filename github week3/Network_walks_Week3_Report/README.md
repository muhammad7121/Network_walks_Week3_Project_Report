## Overview

This repository contains the Week 03 project report for the Networkwalks Academy Cybersecurity Professional Program.

The project documents practical password-cracking exercises performed in a controlled laboratory environment using John the Ripper, the Johnny GUI, and Networkwalks Academy's browser-based password-cracking tools.

The activities were conducted for educational and cybersecurity training purposes.

## What's Covered

### 1. W3-PM1 — Password Cracking with John the Ripper

This section documents the installation and configuration of John the Ripper (Jumbo build) and the Johnny graphical user interface on Windows.

The lab includes:

- Installing John the Ripper.
- Installing and configuring Johnny.
- Configuring Johnny to use the John the Ripper executable.
- Using `pdf2john` to extract password hashes from protected PDF files.
- Performing dictionary-based password-cracking exercises.
- Recovering the passwords/flags from the provided laboratory PDF files.
- Documenting the process with screenshots and results.

### 2. W3-PM2 — Password Cracking with Networkwalks Tools

This section documents password-cracking activities using Networkwalks Academy browser-based cybersecurity tools.

The lab includes:

- Extracting a PDF password hash.
- Identifying the `$pdf$` hash format.
- Using the Networkwalks Hash Calculator.
- Using the Networkwalks Password Cracker through Dictionary Attacks.
- Performing a controlled dictionary attack.
- Verifying the recovered password.
- Documenting the result with screenshots.

## Lessons Learned

The Week 03 project provided practical experience with password security and password-cracking techniques.

Key lessons learned include:

- Passwords should be long, unique, and difficult to guess.
- Hashes can provide useful information for security testing when obtained from authorized laboratory environments.
- Dictionary attacks can be effective against weak or predictable passwords.
- Password-cracking tools should only be used against systems and files for which authorization has been granted.
- Proper documentation is an important part of cybersecurity assessments.
- Strong password policies and secure authentication practices help reduce the risk of password-based attacks.
